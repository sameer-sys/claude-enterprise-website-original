# Claude Enterprise & OpenWork Cloud — Official Website

> The official showcase, architecture, and marketing website for **Claude Enterprise Pro Max & OpenWork Cloud**.

Live App: [https://claude-enterprise-app.vercel.app](https://claude-enterprise-app.vercel.app)

---

## 🌟 Features Showcased
- **Claude 3.7 Sonnet Hybrid Reasoning** (16k - 64k extended thinking budget).
- **260+ OpenWork Autonomous Agents** (Codebase, Research, Systems, Testing).
- **Model Context Protocol (MCP) Connectors** (Gmail, GitHub, PostgreSQL, Linear, Notion).
- **Built-in Native Web Browser & Automation**.
- **Cross-Platform**: Web (Vercel), Windows Desktop (Electron), and Android Mobile (APK).
